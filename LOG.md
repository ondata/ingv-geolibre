# Log

## 2026-10-23

- **Design update**: "Zoom to results" in the panel and "Zoom to" in the table; the area menu is a button opening a list with a country search field; the table no longer opens by itself (user choice), "Show table" opens it. Tried headless on web: country search by typing, 109 events in Italy's box, table closed by default. 25 tests.
- **One layer per search fixed**: GeoLibre 3.4.0 has no `updateGeoJsonLayer` nor `removeLayer` (only on `main`), so every search and every filter change added a project layer in Desktop. Results are now drawn straight on the MapLibre map and replaced by each search (as openrndt-geolibre does); click on a point opens its detail; "Add to layers" in the table keeps a search in the project. Results table: `defaultHeight` 300, because 3.4.0 measures a floating card before the plugin fills it and the table grew off the screen.
- **Interface from the "INGV Panel" design**: right panel with time chips, magnitude and depth double sliders, area combobox (map view, around a point, world, 173 Natural Earth countries); results table in a floating panel at the bottom left; event detail in sections (summary, ShakeMap images and GeoJSON layers, felt reports, magnitude history from QuakeML, seismicity around). Depth classes now 0-10, 10-30, 30-100, >100 km. Tried headless on web.geolibre.app: search, table, detail and country search work; ShakeMap GeoJSON is not readable on web (no CORS). The INGV catalogue outside Italy lists mostly the stronger events.
- **Phase 1**: Search button (last 7 days, M >= 2, map view) on `fdsnws/event`; layer "INGV earthquakes" added with `addGeoJsonLayer` and styled with a Mapbox style through `importLayerStyle` (graduated colour on depth, proportional size on magnitude), updated in place on the next search. Tried in Desktop: 108 events on the Italy view, styled. 14 tests.
- **Scope**: only `fdsnws/event`. Stations, waveforms, shakedata and sqlx checked and left out.
- **Desktop try**: dev copy `ingv-geolibre-dev` 0.0.0 installed in GeoLibre Desktop (Windows); the empty "INGV (dev)" panel opens on the right. Web try on web.geolibre.app (manifest from localhost:8000): the "INGV" panel opens, Diagnostics 0.
- **Phase 0**: repo created from the skeleton of openrndt-geolibre (build, dev copy with CSS prefix `ingq-`/`ingqdev-`, packaging, install, serve scripts, host API types). Plugin `ingv-geolibre` 0.0.0 with an empty right panel. `tsc`, 3 tests, lint, build, dev build and zip pass.
- **INGV FDSN event service checked**: CORS `*`, native `format=geojson`, filters on time, magnitude, depth, box and radius; 13,521 events from 2026-01-01 in one response; CC BY 4.0. Event page `terremoti.ingv.it/event/<id>` answers 200.
